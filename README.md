# Portfolio (React + Vite)
1. `npm install`
2. `npm run dev`  (open the local link)
3. `npm run build` for the final site (folder `dist`)

- Colors: `theme.css` (project root)
- Texts (EN/RU), name, contacts, photo path: `src/content.js`
- Photo: copy it into `public/` (e.g. photo.jpg) and set `PHOTO = '/photo.jpg'` in `src/content.js`
